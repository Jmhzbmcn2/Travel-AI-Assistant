# Roadmap

## 0-2 Months

- Clean package layout and product harness.
- Fix plan editing after HITL so users do not lose session context.
- Add structured trip plan UI.
- Add rule-based validators for missing fields, low budget, and dense schedule.

## 3-6 Months

- Add decision engine with cost and route feasibility scoring.
- Add export/share itinerary.
- Add lead capture for travel agency handoff.
- Add provider abstraction for travel APIs.

## 6-12 Months

- Add personalization and trip preference memory.
- Add supplier or agency partnerships.
- Add dashboard for leads and itinerary operations.
- Track conversion and revenue metrics.
