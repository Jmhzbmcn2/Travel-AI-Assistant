# AI Behavior

## Use AI For

- Understanding natural-language trip requests.
- Drafting structured trip plans.
- Summarizing reviews or destination notes.
- Explaining trade-offs in Vietnamese.

## Avoid AI For

- Math and cost totals.
- Routing and state transitions when deterministic rules are enough.
- API response normalization.
- Required-field validation.
- Rate limiting, cost controls, and guardrails.

## Response Standard

Be specific about assumptions. Do not present estimates as confirmed prices. Include source or timestamp when external data is used.
